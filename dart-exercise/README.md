## Description

This project is a simple **Point of Sale (POS) System** created using Dart. It demonstrates basic Dart programming concepts by allowing the user to select products, enter quantities, calculate the total amount, and display the transaction summary.

The program can be written and tested using Visual Studio Code with the Dart SDK installed.

## Features

- Displays available products and their prices
- Allows the user to select a product
- Accepts the quantity of the selected product
- Calculates the subtotal and total amount
- Displays a simple transaction summary
- Uses basic Dart concepts such as variables, conditions, loops, and user input

## Getting Started

### Requirements

Before running the program, make sure the following are installed:

- Visual Studio Code
- Dart SDK
- Dart extension for Visual Studio Code

## Usage

Open the project folder in Visual Studio Code.

Open the terminal and run:

```bash
dart dart-exercise.dart
```

Follow the instructions displayed in the terminal to use the POS System.

## Example

The program may ask the user to:

1. Select a product.
2. Enter the quantity.
3. Add the selected product to the transaction.
4. Calculate the total amount.
5. Display the final transaction summary.

## Purpose

This activity was created to practice the fundamentals of Dart programming through a simple POS System scenario.
